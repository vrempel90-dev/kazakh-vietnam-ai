# Чартерные авиабилеты — Telegram Mini App

Мобильный прототип поиска и подбора чартерных рейсов. Сохранены исходный синий header, светлые карточки, скругления, адаптивная оболочка iPhone/Pixel 10 и светлая/тёмная темы.

## Возможности

- Главный экран с восемью подборками рейсов и пятью пунктами нижней навигации.
- Поиск по направлению, городу вылета, дате или периоду, типу билета и бюджету.
- Избранные рейсы и сохранённые параметры уведомлений в `localStorage`.
- Карточка рейса с маршрутом, датой, типом билета и ориентировочной ценой.

**Данные о рейсах и ценах демонстрационные.** Поставщик билетов, актуальное наличие, отправка Telegram-уведомлений, бронирование и оплата пока не подключены. Интерфейс явно отмечает это, чтобы примерные цены не выглядели реальными предложениями.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run test:runtime
npm run test:sites
npm run build
```

`npm test` открывает приложение в установленном Google Chrome, проверяет основной сценарий и делает снимки на ширинах 375, 390 и 430 px в папке `screenshots/`. `test:runtime` проверяет жесты, клавиатуру, BottomSheet и навигацию на Chrome. Мобильный runtime дополнительно проверяется командой `npm run check:runtime` при запуске и сборке.

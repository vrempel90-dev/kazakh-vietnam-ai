# Чартерные авиабилеты — Telegram Mini App

Мобильный прототип поиска и подбора чартерных рейсов. Сохранены исходный синий header, светлые карточки, скругления, адаптивная оболочка iPhone/Pixel 10 и светлая/тёмная темы.

## Возможности

- Главный экран с восемью подборками рейсов и пятью пунктами нижней навигации.
- Поиск по направлению, городу вылета, дате или периоду, типу билета и бюджету.
- Избранные рейсы и сохранённые параметры уведомлений в `localStorage`.
- Карточка рейса с маршрутом, датой, типом билета и ориентировочной ценой.

**Данные о рейсах и ценах демонстрационные.** Поставщик билетов, актуальное наличие, отправка Telegram-уведомлений, бронирование и оплата пока не подключены. Интерфейс явно отмечает это, чтобы примерные цены не выглядели реальными предложениями.

## Проект Charter Aggregation Engine

- [Архитектура агрегатора](docs/charter-aggregation-architecture.md): источники, модель, ценообразование, дедупликация, синхронизация, публикация, повторная проверка, заявки и админка.
- [Отчёт об источниках](docs/source-integration-report.md): технический статус 13 партнёров, двух Telegram-каналов и требования к доступам.

Текущий production pipeline намеренно не использует Telegram-каналы как источник предложений. Telegram служит только каналом публикации и интерфейсом.

Подключён внешний reader для NEOS Google Sheet: строки читаются и нормализуются, но предложение допускается в публикацию только после подтверждения валюты себестоимости и применения правила наценки. Валюта берётся из настройки или из однозначного явного маркера в самой таблице; по величине числа она не угадывается.

B2B-сайты партнёров сейчас мониторятся диагностически. До появления подтверждённого API/feed, разрешённого browser/network flow или выданных B2B-доступов они не считаются production-источниками тарифов и не могут создавать предложения. Это защищает от публикации выдуманных или непроверенных цен.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run test:runtime
npm run test:sites
npm run build
```

`npm test` открывает приложение в установленном Google Chrome, проверяет основной сценарий и делает снимки на ширинах 375, 390 и 430 px в папке `screenshots/`. `test:runtime` проверяет жесты, клавиатуру, BottomSheet и навигацию на Chrome. Мобильный runtime дополнительно проверяется командой `npm run check:runtime` при запуске и сборке.
